## How to use this manual

- If you are installing the server, start with Requirements, installation, and configuration.
- If you are integrating the frontend or Postman, review Sessions and authentication first.
- If you are managing the school, consult the role-based workflows and then the corresponding module.
- If a request fails, use the HTTP status code table and the troubleshooting guide.
- For quick reference, use the consolidated endpoint catalog in the appendix.
